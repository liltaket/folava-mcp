# Project identity

The Folava MCP mark is an original drawing of two overlapping note sheets,
with a folded lower edge. It represents bringing course context into another
workspace. It uses no logo, monogram or visual assets from the Folava GUI project.

The editable source is `site/assets/mark.svg`. The documentation builder uses
that same geometry in the wordmark, synthetic example and generated favicon.
Keep it monochrome, preserve its proportions and leave room around its outline.
Use the full project name in nearby text or an accessible link label; the mark
does not need to carry a second screen-reader name.

The independent-project and Canvas trademark notices remain part of the project.
The mark does not imply institutional or Instructure affiliation.
